xclean

Real-time stereo visual-inertial SLAM, built in India. Python, with GPU code written in CuPy and CPU hot paths in Numba: no C++ build step, no ROS. It runs natively on Windows 11 and is built for a Luxonis OAK-D-Lite stereo camera.

What it does

xclean estimates the pose of a stereo camera at every frame, while it moves. Every pose is published live from a solve that contains that frame, and loop corrections are applied live.

xclean is a stereo visual-inertial SLAM system: it uses the IMU while a built-in consistency check accepts it, and otherwise continues as stereo visual odometry with loop closure. In the final board the IMU stayed in use to the end on 50 of 216 runs (mostly EuRoC and 4Seasons). On MADMAX, Rosario and our own OAK-D-Lite recordings the check dropped or refused it. KITTI has no IMU. Per dataset.

  • On the GPU: feature detection, ORB descriptors, stereo matching, and the first feature-matching step of each frame.
  • Inertial, on the CPU: IMU preintegration, with an online consistency check (it can drop or refuse the IMU) and an online camera-IMU clock-offset estimate.
  • Back end on the CPU (Numba): matching against the local map, and the sliding-window factor graph that gives each frame its pose.
  • Full SLAM: loop closure, relocalisation and map reuse, in a separate CPU process outside the frame path; their corrections are applied to the published pose live.
  • No learned networks in the SLAM pipeline.

"Written in CuPy" does not mean "pure Python": CuPy compiles our CUDA C source at first use (NVRTC), and the CPU hot paths are compiled by Numba.

Install and run

Install and run instructions will be published with the code.Download xclean 0.1.0 (source code, zip, 1.3 MB), or clone it: git clone https://github.com/necessityrobotics/xclean. Install and run instructions are in its README. What you will need: Windows 11 (64-bit), an NVIDIA GPU with a driver that supports CUDA 13 (R580 or newer), and conda. No CUDA Toolkit is needed: the conda environment carries the CUDA kernel compiler.

Known limits

Tested on one machine: AMD Ryzen 9 9950X, NVIDIA RTX 5090, Windows 11. Other CPUs, GPUs and drivers, Linux and macOS are not tested. At start-up the GPU front end checks itself against the CPU code; if a check fails, xclean says so and runs the whole route on the CPU front end, with higher latency.
