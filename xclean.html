xclean

Real-time stereo visual-inertial SLAM, built in India. Python, with GPU code written in CuPy and CPU hot paths in Numba: no C++ build step, no ROS. It runs natively on Windows 11 and live on a Luxonis OAK-D-Lite stereo camera.

What it does

xclean estimates the pose of a stereo camera with an IMU at every frame, while it moves. Every pose is published live from a solve that contains that frame, and loop corrections are applied live.

  • Front end on the GPU: stereo feature tracking.
  • Inertial: IMU preintegration, with the IMU's trust and the camera-IMU clock offset handled online.
  • Back end on the GPU: a sliding-window factor graph.
  • Full SLAM: loop closure, relocalisation and map reuse.
  • No learned networks in the SLAM pipeline.

"Written in CuPy" does not mean "pure Python": CuPy compiles our CUDA C source at first use (NVRTC), and the CPU hot paths are compiled by Numba.

Install (Windows 11, NVIDIA GPU)

You need an NVIDIA GPU, an NVIDIA driver that supports CUDA 13 (tested: driver 616.92 on an RTX 5090), and conda (Miniconda or Anaconda). From the repository root:

conda env create -f environment.yml
conda activate xclean
pip install -e .
xclean --help
  • environment.yml installs Python 3.12, NumPy, SciPy, Numba, psutil, CuPy 13.6 with the conda-forge CUDA 13.0 libraries, OpenCV and depthai. Creating it took about 10 minutes and 2.8 GB on our machine.
  • On Windows, always activate the environment (conda activate xclean, or conda run -n xclean ...). Calling the environment's python.exe directly does not work, because its DLL folder is then not on PATH.
  • Do not add the [cuda13] or [cuda12] extras inside the conda environment: CuPy is already installed there.

Check the install (CPU only, no datasets, a few seconds):

pip install pytest
pytest

Run

xclean reads a sequence folder: calib.json, timestamps.csv, left/, right/, optionally imu.jsonl and gt.csv. The format is described in docs/SEQUENCE_FORMAT.md in the repository.

Replay a recorded sequence

The live engine, frame by frame without dropping frames (lock-step), then the live scorer against ground truth:

xclean replay <sequence dir> --out runs/mh04 --mode lockstep --env XCLEAN_ENGINE=p1 --gt <.../mav0/state_groundtruth_estimate0/data.csv>
python -m xclean.live.score_live runs/mh04 --gt <the same data.csv>

--mode paced replays at the recorded frame rate, for latency measurement on an otherwise idle machine.

Live on an OAK-D-Lite

A view window opens; q or Esc stops.

xclean live --out runs/live1 --record recordings/live1 --duration 120

The other commands are xclean run (offline runner), xclean score (score a trajectory against ground truth) and xclean audit (check sequence folders). xclean <command> --help lists the options of each.

Tested, and not yet

Tested

  • Windows 11, conda environment from environment.yml, NVIDIA driver 616.92, RTX 5090.
  • The final board: 216 live paced runs on 72 routes, with one frozen build.
  • Live on our own OAK-D-Lite camera.

Not tested yet

  • A clean Windows 11 machine without the CUDA Toolkit. Until then we do not claim the toolkit is unnecessary.
  • A pip-only install (the [cuda13] / [cuda12] extras).
  • Smaller GPUs and Linux. All timings come from one desktop.
  • A converter from the EuRoC ASL layout to the sequence format is not included yet.
