Who we are

No robot body yet. The first part works today: live SLAM, the software that tells a robot where it is. A lost robot cannot work, so we built this first.

Our goal

A robot whose work you cannot tell from a person's.

Engineers call this the physical Turing test. We see a future of physical AI: robots that do real tasks as well as people, then better.

What we are building

These are aims. None of these robots is done yet.

  • Robot hands that hold and move real objects like a person does.
  • Humanoid robots.
  • Robots for edge cases: jobs that are too dangerous or too hard for people.
  • Surveillance technology for defence.

A robot needs five layers. We aim to build every one of them ourselves.

  1. Energy: not built yet
  2. Semiconductors: not built yet
  3. Hardware: not built yet
  4. Software first part works
  5. Product: not built yet

Lit = a first part works today. Dashed = not built yet.

What works today

Two products, both in the software layer.

Live SLAM xclean Tells a robot where it is, from a calibrated stereo camera. Live with any such rig (side by side, pinhole lenses, both images at the same time). We tested live runs only on the OAK-D-Lite. Released. Open source, Apache-2.0. Free, also for commercial use. Zero-shot ML Depth model How far away each point is, from two camera photos. No retraining for your camera. Our 3-D places take their depth from it. nrs-large: Free download.

Our map builder, xclean-maps, is open source too. Its version 0.1.0 uses classic depth. The version that uses our depth model, and made these places, is not released yet.
